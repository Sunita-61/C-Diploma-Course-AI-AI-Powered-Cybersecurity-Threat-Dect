# Experimental Notebooks

This folder contains step-by-step interactive Jupyter notebooks demonstrating the research, exploration, and modeling phases of the Threat Detection System.

## Notebook Inventory:
1. `01_data_exploration.ipynb`: Exploratory data analysis (EDA) of network activity and distributions.
2. `02_data_preprocessing.ipynb`: Demonstrates missing value imputation, deduplication, and leakage prevention.
3. `03_feature_engineering.ipynb`: Shows defensive ratio engineering (failure rates, bandwidth usage, watchlist flags).
4. `04_model_experiments.ipynb`: Experiments with Random Forest, Logistic Regression, and Isolation Forest anomaly detection.

## How to Run:
Launch Jupyter Lab or Notebook from the project root:
```powershell
pip install jupyter
jupyter notebook notebooks/
```
