# Project Screenshots & Visual Assets

This directory stores screenshots and architecture diagrams generated from running the application.

## Screenshots to Add:
1. `dashboard_overview.png`: Full Streamlit dashboard overview showing KPI cards and event activity.
2. `detection_insights.png`: Severity distribution charts and attack category breakdowns.
3. `model_evaluation.png`: Confusion matrix and performance metrics display.
4. `alerts_export.png`: Structured alerts table with filtering and CSV export option.

### How to Capture Screenshots:
1. Launch the Streamlit dashboard:
   ```powershell
   streamlit run app/dashboard.py
   ```
2. Navigate the dashboard using Synthetic Demonstration mode or an uploaded dataset.
3. Use Windows Snipping Tool (`Win + Shift + S`) or browser developer tools to capture clean screenshots.
4. Save the captures into this directory and reference them in the main `README.md`.
